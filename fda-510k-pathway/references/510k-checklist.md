# FDA 510(k) 提交文件清单

> 数据来源：《合规之战：全球医疗器械监管进化史》第三章和第十三章

## 完整提交文件清单

| # | 文件 | 适用类型 | 写作要点 |
|---|------|---------|---------|
| 1 | 510(k) Cover Sheet (Form FDA 3514) | 全部 | 在线填写 eSTAR |
| 2 | 用户费用支付凭证 | 全部 | FY2026 标准 **$26,067** / 小企业 **$6,517**（须提前申请 SBD 认定） |
| 3 | 510(k) Summary 或 Statement | 全部 | Summary 可被公众查阅；Statement 仅向 FDA 开放 |
| 4 | 实质等同性论证表（12列对比） | 全部 | 核心文件——每个差异必须论证不影响安全有效性 |
| 5 | 器械描述 | 全部 | 含设计图/照片/预期用途/工作原理 |
| 6 | 对比器械信息 | 全部 | predicate 标签 + 510(k) Summary |
| 7 | 性能测试报告（非临床） | 全部 | 精度验证、可靠性测试 |
| 8 | 生物相容性报告 | 如有组织接触 | ISO 10993 系列 |
| 9 | 软件文档 | 如含软件 | IEC 62304 生命周期 |
| 10 | 电磁兼容报告 | 如有源 | IEC 60601-1-2 |
| 11 | 灭菌验证 | 如灭菌提供 | ISO 11135(EO) 或 ISO 11137(辐照) |
| 12 | 标签 | 全部 | 产品标签+包装标签+IFU |
| 13 | Truthful and Accurate Statement | 全部 | 声明所有提交信息真实准确 |

## 判定标准

- ✅ 差异不影响安全性和有效性 → 实质等同成立
- ⚠️ 差异引入新安全性/有效性问题 → 需要额外测试数据
- ❌ 差异改变预期用途 → 不是同一类器械，换 predicate

## 三种提交类型

| 类型 | 适用场景 | 审查周期 | 提交要点 |
|------|---------|---------|---------|
| Traditional 510(k) | 标准路径 | 90天 | 最常用，完整提交 |
| Abbreviated 510(k) | 已遵循FDA认可标准 | 90天 | 引用标准编号，减少测试论证 |
| Special 510(k) | 已获批器械的设计变更 | 30天 | 变更不影响安全有效性 |

## 510(k) 审查流程时间线

```
Submit → FDA收到 → Refuse to Accept (RTA) 检查（15天）
                         │
                    ┌─────┴─────┐
                    ▼           ▼
               通过RTA       RTA不通过
                    │           │ → 补充缺失文件 → 重新提交
                    ▼
              实质性审查（60天）
                    │
               ┌────┼────┐
               ▼         ▼
          AI Request  SE Letter
          (补充信息)   (实质不等同)
               │         │ → 需额外数据或换predicate
               ▼
          审查继续
               │
               ▼
          获批 → SE (Substantially Equivalent)
```

## Predicate Device 查找策略

1. 在 FDA Product Classification Database 搜索产品代码
2. 在 FDA 510(k) Database 搜索该代码下最近获批的 510(k)
3. 优先选择近 5 年内获批的 predicate
4. 查看 predicate 的 Indications for Use Statement
5. 如有多种选择，选技术特征最接近的
