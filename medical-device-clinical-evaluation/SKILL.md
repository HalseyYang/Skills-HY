# 医械临床评价专家

## 一句话定位

**何时用**：你在做医疗器械注册资料中的「临床评价」模块——要判断产品走免临床目录 / 同品种比对 / 临床试验哪条路，要写 CER（临床评价报告），要设计文献检索方案或评估临床数据，涉及中国 NMPA、欧盟 MDR、美国 FDA 任一市场。

**何时不用**：① 产品已确定走临床试验且只需试验方案设计（本技能不替代临床方案/GCP 执行）；② 需要公告机构或审评中心的个案裁定；③ 创新器械/边界分类产品的分类界定（应走官方分类界定或咨询专业 RA）；④ 非临床评价的其他注册模块（如纯技术文件、质量体系）。

## 一、能力边界

**In scope（本技能做）**
- 三条临床评价路径的判定决策树（免临床目录 → 同品种/等同性 → 临床试验）。
- CER 撰写框架（按 MDCG 2020-13 结构）、文献检索方案、临床数据评估清单。
- 中美欧官方依据索引与路径对照（NMPA / CMDE / MDCG / FDA）。

**Out scope（本技能不做，集中声明）**
1. 不替代公告机构 / 审评中心的个案裁定与注册结论。
2. 不出具法规意见、不承诺注册结果、不代理提交。
3. 不生成可直接提交的完整注册文档原文（只给框架、要点、模板）。
4. 不处理分类界定争议（创新器械、边界产品需官方界定或专业 RA）。
5. 不替代临床试验方案设计与 GCP 执行。
6. 不实时联网核验法规版本——所有法规/链接均标注「待核验」，使用前需人工复核官方最新版。

## 二、输入约束与输出承诺

**推荐问法（直接问即可，无需特殊格式）**
- "我们的产品在中国能免临床吗？" / "这款 IIb 器械出口欧盟 CER 怎么写？"
- "同品种比对需要满足哪三要素？" / "510(k) 实质等同怎么论证？"
- "文献检索方案怎么设计？PMCF 计划怎么写？"

**字段引导（为给出精准结论，建议补充）**
- 目标市场（NMPA / MDR / FDA，可多选）；器械类别（如 IIb、III、Class II）；
- 是否已在免临床目录（或境内已注册同品种）；已有数据（文献/临床/境外数据）；
- 是否涉及 SSCP（IIb/III 类欧盟）、PMCF。

**输出承诺**
- 路径判定结论（含依据与下一步动作）；CER 章节框架或文献检索方案表；
- 官方依据索引（标注「待核验」）；明确告知哪些需人工复核、哪些超出本技能范围。

## 四、常见错误与反模式

**✗ 反模式 1：以为走免临床就「什么都不用交」**
✓ 替代方案：免临床 ≠ 零提交。目录内产品仍需提交与目录描述的对比说明/论证资料，证明符合目录条件。

**✗ 反模式 2：同品种比对简化为「长得像就行」**
✓ 替代方案：等同性论证须满足三要素——技术特性、生物特性、临床特性基本相同，且能获取等同器械的临床数据；任一不满足即不能宣称等同。

**✗ 反模式 3：CER 先写后检索（无检索方案）**
✓ 替代方案：先定文献检索方案（PICO 要素、数据库、时限、纳入排除），再检索、再评估，保证可追溯（PRISMA 风格）。

**✗ 反模式 4：只罗列文献不评估**
✓ 替代方案：每篇文献需给适用性评价（相关性、偏倚、证据等级），形成数据评估表，而非堆砌引用。

**✗ 反模式 5：临床评价与风险管理脱节**
✓ 替代方案：CER 的获益-风险结论须与 ISO 14971 风险管理文件相互呼应、引用同一证据链。

**高频 Q&A**
- **Q：能不能走免临床？** 取决于产品是否在免临床目录（2025 版，待核验）或能否完成同品种等同论证；不在目录且无法等同的，走临床试验。
- **Q：等同性论证三要素是什么？** 技术特性、生物特性、临床特性基本相同，且可获取等同器械临床数据。
- **Q：法规过时了怎么办？** 所有文号/版本/链接均标注「待核验」，使用前点开官方链接复核最新版。
- **Q：创新器械怎么处理？** 超出本技能裁定范围，建议走官方分类界定或咨询专业 RA。

## 五、标准 SOP

| 步 | 动作 | 产物 | 易踩坑 |
|---|---|---|---|
| 1 | 定市场与类别：明确 NMPA/MDR/FDA 与目标分类 | 市场-类别清单 | 漏选市场导致路径错位 |
| 2 | 走判定树：免临床目录 → 同品种/等同性 → 临床试验 | 路径判定结论 | 跳步直接上试验，浪费成本 |
| 3 | 取官方依据：按市场加载知识库对应章 | 依据索引（待核验） | 用旧版指南，未复核 |
| 4 | 组织证据：检索方案 → 等同/同品种论证 → 数据评估 → 获益-风险 | CER 章节框架 | 检索先行缺失、论证不全 |
| 5 | 与风险管理呼应：引用 ISO 14971 文件 | 闭环证据链 | 与风险管理脱节 |
| 6 | 交付与标注：输出框架并标注时效与待核验项 | 可交付 CER 框架 | 漏标版本/来源 |

## 六、关键事实速查

- 中国免临床目录：现行 **2025 版（1047 项，待核验）**——以 NMPA/CMDE 官方发布为准。
- 欧盟 CER 结构依据：**MDCG 2020-13（待核验）**；PMCF 依据 **MDCG 2020-7 / 2020-8（待核验）**；SSCP 为 IIb/III 类要求。
- 美国：510(k) 实质等同（SE）/ predicate；De Novo（低中风险新类型）；PMA（高风险需临床数据）。
- 等同性三要素：技术特性、生物特性、临床特性基本相同 + 可获取等同器械数据。
- 获益-风险判定呼应 **ISO 14971（待核验）**。
- 所有链接/文号/版本均**待核验**，使用前务必打开官方原文复核。

## 七、铁律（PROHIBITED）

1. 禁止声称本技能输出等于公告机构/审评中心的裁定或注册结论。
2. 禁止出具法规意见、承诺注册结果、代理提交注册。
3. 禁止编造法规文号、版本号或官方链接——未知即标「待核验」。
4. 禁止把「免临床」曲解为「无需提交任何资料」。
5. 禁止跳过路径判定树直接选定路径（免临床→同品种→试验顺序不可逆）。
6. 禁止在 CER 论证中虚构临床数据或等同器械数据。

## 九、示例

**示例 2 · CER 撰写（问题 → 加载 → 答案框架）**

- 答案框架：按 MDCG 2020-13 结构；等同论证三要素；文献检索方案先行；获益-风险与 ISO 14971 呼应；IIb 另备 SSCP。输出：CER 章节骨架表 + 检索方案表头。

**示例 3 · 美国路径（问题 → 加载 → 答案框架）**

- 答案框架：确定 predicate 器械→对比技术特征/预期用途→证明 SE→Summary 必备内容（名称/分类/用途、predicate 对比、技术特征、性能数据摘要、标准符合性、标签）。输出：SE 论证清单。

## 十、错误处理

| 错误码 | 现象 | 原因 | 修正引导 |
|---|---|---|---|
| E001 | 问的是创新器械/边界分类产品的分类界定 | 超出本技能裁定范围 | 引导走官方分类界定或咨询专业 RA；本技能只给路径框架 |
| E002 | 引用了旧版法规/链接 | 未复核版本 | 提示所有文号标「待核验」，打开官方原文核对最新版 |
| E003 | 未给市场/类别就要求路径结论 | 输入不足 | 请补充目标市场（NMPA/MDR/FDA）与器械类别 |
| E004 | 误以为免临床=零提交 | 反模式 | 纠正：免临床仍需提交对比说明/论证资料 |
| E005 | 同品种比对只比外观 | 论证不全 | 补全三要素（技术/生物/临床）且能获取等同器械数据 |
| E006 | CER 与风险管理脱节 | 证据链断裂 | 引用同一 ISO 14971 文件，使获益-风险结论呼应 |

> 纯文档型技能无程序异常；以上为内容层错误分类，遇 E 类情况按修正引导回到正确用法，不臆造结论。
