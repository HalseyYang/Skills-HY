## 1. 来源优先级

### 美国 FDA

优先使用 `fda.gov`、FDA Product Classification Database、510(k) Premarket Notification、De Novo、PMA、Recognized Consensus Standards、Medical Device User Fee 等官方页面或数据库。

### 欧盟 CE MDR

优先使用 EUR-Lex 上 Regulation (EU) 2017/745 的现行合并文本、European Commission 医疗器械页面、NANDO、EUDAMED 公共页面和官方 MDCG 文件。MDCG 属指导文件，不能替代法规原文。

### 标准

优先使用 ISO、IEC、CEN/CENELEC、ANSI/AAMI 等发布方目录以及欧盟协调标准官方决定/清单、FDA Recognized Consensus Standards。标准正文可能付费；不得从非授权转载页假装取得全文。

### 其他

NB 费率以该 NB 官方费率表或正式报价为准。行业文章、咨询机构页面、搜索摘要、聚合站和生成式回答只能用于发现线索，不能单独支持客户方案中的关键结论。

## 2. 必须实时核验的事项

- 法规是否现行、修订与过渡期
- FDA classification、product code、exemption 和 submission type
- 510(k)、De Novo、PMA 编号、申请人、设备名、决定日期和状态
- FDA 当年度用户费、企业注册费及小企业条件
- MDR 分类规则和符合性评估附件
- NB 的 MDR 指定状态、机构号和 scope
- EUDAMED/UDI 实施安排
- 标准版本、修订版、撤销/替代状态、FDA认可或欧盟协调状态
- 官方或第三方费用、汇率与查询日期

不要沿用样例中的年份、金额、排期或数据库数量。

## 3. 证据记录格式

每条关键结论记录：

| 字段 | 要求 |
|---|---|
| 结论 | 一句话，含适用条件 |
| 官方机构 | FDA、European Commission、EUR-Lex、NANDO 等 |
| 页面/文件 | 官方标题，不写搜索结果标题 |
| 链接 | 直达页面或文件 |
| 版本/日期 | 页面更新日、法规合并版本或标准版本 |
| 查询日期 | 使用任务当天日期 |
| 证据范围 | 该来源具体支持什么，不扩大解释 |

客户正文就近放置可点击链接；末尾附精简的“法规核验记录”。引用时以转述为主，不大段复制原文。

## 4. 冲突与失败处理

- 官方来源之间冲突：优先法规原文和较新发布内容，并明确差异。
- 数据库记录与指南冲突：分别说明其作用，不自行消除冲突。
- 页面不可访问或检索失败：标记“待人工确认”，不给确定结论。
- 只有二手来源：可以提出待核验线索，不得进入确定报价或路径结论。
- 不能确认标准版本：只写测试类别和“版本待实验室/认证机构确认”，不得猜编号。
