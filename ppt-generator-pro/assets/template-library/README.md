This folder stores reusable PPT/PPTX templates for future presentation work.

Before creating a new PPT, ask the user whether to use:

1. The company PPT template.
2. One of the reusable templates in this library.
3. Another requested style.

## Use Rules

- Inspect a selected template before generating or editing slides.
- Reuse layouts and visual language from the template rather than inventing a new visual system.
- For template-driven decks, duplicate existing slides/layouts where practical.
- Normalize fonts, colors, spacing, and table treatments after combining with other templates.
- Render or visually inspect final slides before reporting completion when layout fidelity matters.
