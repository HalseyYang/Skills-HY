# CER（临床评价报告）审核级撰写指南

> **用途**：CER 是 MDR 技术文档中 NB 审核最深的文件。本指南按 **MEDDEV 2.7/1 Rev.4 + MDCG 2020-13** 给出审核级 CER 的十章结构、等同性论证、文献检索与评价方法——目标：NB 审核员推不出实质性缺口。

---

## 1. 法规基础

- **MDR Article 61**：制造商按 Annex XIV 持续更新 CER
- **Annex XIV**：临床评价与临床数据（CEP → CER → PMCF 循环）
- **MEDDEV 2.7/1 Rev.4**（2016）：临床评价方法学经典指南
- **MDCG 2020-13**：CER 评估要点（NB 视角）
- **MDCG 2020-5**：等同器械论证指南（临床/技术/生物三要素）
- **ISO 14155**：临床调查的设计与执行（如做新临床研究）
- **更新频率**：Class IIa 至少每 2 年（Article 86(2)(a)）；Class IIb/III 至少每年（Article 86(2)(b)）；Class III 植入式须临床数据支撑（Article 61(4)）

---

## 2. 审核级 CER 十章结构

| 章 | 内容 | NB 审核关注点 |
|----|------|-------------|
| **1. 临床评价计划（CEP）** | 范围、方法、等同性策略、文献策略、输出物 | 计划先行，不能「先做后补」 |
| **2. 器械描述与预期用途** | 与主数据表一致；预期用途、人群、使用环境、禁忌 | 与 EUDAMED/IFU 一致 |
| **3. 临床背景与 SOTA** | 当前诊疗路径、现有方案、未满足需求 | 证明你知道「现在最好的是什么」 |
| **4. 文献检索与数据识别** | PICO + 数据库 + 检索式 + 日期 + 纳排标准 + PRISMA | **可复现**是硬指标 |
| **5. 数据评估** | 每篇文献的显著性 + 适用性评价 | 评价维度留痕，不是只列结论 |
| **6. 数据分析与综合** | 安全性/有效性/性能数据综合；定量/定性方法 | 数据间矛盾如何处理要说明 |
| **7. 等同器械论证** | 三要素论证（见下节） | MDCG 2020-5 附录逐项 |
| **8. 收益-风险结论** | 显式结论 + 残余风险 | 结论段必须明确可引用 |
| **9. 评估者资质与签字** | CV + 利益声明 + 临床资质专家签字 | TEAM-NB 明确要求 |
| **10. PMCF 计划与中期报告** | 缺口 → PMCF 行动 → 中期报告回填 | PMCF 必须挂回 CER 缺口 |

---

## 3. 等同器械三要素（MDCG 2020-5）

| 要素 | 论证内容 | 常见缺口 |
|------|---------|---------|
| **临床特征** | 预期用途、目标人群、病症、使用条件、侵入性 | 人群差一点没论证 |
| **技术特征** | 设计、材料/组成、能量类型、算法、软件、灭菌 | 「基本相同」一句话式论证 |
| **生物特征** | 生物学行为：代谢、毒性、免疫反应、降解 | 直接漏掉这一要素 |

**规则**：三要素全部等同 → 等同成立，可用其临床数据；部分不等同 → **必须补充数据弥补差距**（追加测试/研究/文献），且差距要在 CER 中显式讨论。

**⚠️ Class III 植入式**：Article 61(4)——等同路径还须提供**临床数据**，纯等同论证不够。

## 4. 文献检索可复现性清单

1. **PICO 拆解**：人群(P)/干预(I)/对照(C)/结局(O) 转成检索概念
2. **数据库清单**：PubMed/MEDLINE、Embase、Cochrane 等，写明检索日期范围
3. **检索式原文**：每个概念块的检索词 + 布尔逻辑（可粘贴复现）
4. **纳排标准**：纳入/排除理由逐条列
5. **PRISMA 流程**：识别→去重→初筛→全文评估→纳入 各步骤数量
6. **灰色文献/监管数据库**：FDA MAUDE/EUDAMED 警戒、召回信息（SOTA 的一部分）

**自检**：把检索式交给第三方研究员，能复现同样的命中集吗？

---

## 5. 文献评价双维度

| 维度 | 评价内容 | 留痕方式 |
|------|---------|---------|
| **显著性（Significance）** | 研究设计、样本量、偏倚风险、统计方法 | 评价表（逐研究） |
| **适用性（Applicability）** | 与本品的人群/用途/技术差异是否影响外推 | 适用性论证段 |

**分级策略**：高证据等级（RCT/系统评价）优先；低等级（病例系列/专家意见）仅作补充，须说明理由。

---

## 6. 收益-风险结论写法（审核级）

```
结论段必须包含：
① 临床证据的强度总结（数据类型/数量/质量）
② 收益：已证实的临床收益（引用具体数据）
③ 风险：残余风险清单（引用风险文件编号）
④ 权衡结论：收益大于残余风险（显式语句）
⑤ 局限性：证据缺口 + PMCF 如何弥补
```

---

## 7. PMCF 衔接（MDCG 2020-7）

- PMCF 的每一项行动 ↔ CER 中一个具体缺口/问题
- PMCF 中期报告 → CER 更新的输入
- 更新 CER 时，PMCF 数据须**实质性回填**（不是「已收集，无变化」）

---

## 8. 常见退回 + 自检 15 问

**高频退回**：检索不可复现 / 评估者无 CV / 三要素缺腿 / 结论段含糊 / PMCF 与 CER 脱节 / 预期用途与 IFU 不一致。

**自检 15 问**：
1. CEP 是否在 CER 之前定稿？
2. 预期用途与主数据表逐字一致？
3. 检索式可复现吗？
4. PRISMA 流程数字自洽吗？
5. 每篇文献有双维度评价表吗？
6. 三要素各有独立论证段吗？
7. 不等同处有数据补位吗？
8. 结论段五要素齐全吗？
9. 评估者 CV + 利益声明 + 临床签字齐吗？
10. PMCF 每项挂回 CER 缺口吗？
11. 更新频率符合 Class 要求吗（IIa 2 年/IIb-III 1 年）？
12. Class III 植入式有临床数据吗？
13. 引用标准现行版吗？
14. 文献语种/翻译处理说明了吗？
15. CER 有文档编号+版本+日期吗？
