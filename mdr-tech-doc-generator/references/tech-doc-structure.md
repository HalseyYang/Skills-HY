# MDR Annex II 技术文档结构详解

> 数据来源：《合规之战：全球医疗器械监管进化史》第十三章

## Module A: 器械描述与规格

- 产品名称、型号、变体
- 预期用途/适应症
- 禁忌症
- 目标用户（专业/家庭）
- 目标人群（成人/儿童/新生儿）
- 器械历史（前代产品、设计演变）
- 法规状态（是否为新产品/升级/继承）

## Module B: 设计与制造信息

- 设计图纸和组件清单
- 材料清单及规格（含供应商）
- 制造流程图
- 关键工艺和外包过程
- 包装设计
- 灭菌过程（如适用）

## Module C: GSPR 符合性检查表

逐条对照 MDR Annex I 的 23 条通用安全与性能要求：
- GSPR 1-9：通用要求（安全、风险、性能、材料、运输存储等）
- GSPR 10-16：设计制造（有源器械、辐射、软件、含药器械等）
- GSPR 17-22：信息要求（标签、IFU、UDI等）
- GSPR 23：标签和说明书要求

每条必须包含：条款原文 + 证明方式 + 证据文件引用

## Module D: 收益-风险分析

- 基于 ISO 14971 的风险管理报告（RMF）
- 收益-风险比的总体评价
- 残余风险的可接受性论证
- FMEA / FTA 等风险分析工具的运用

## Module E: 产品验证与确认

- 性能测试：精度、可靠性、耐久性
- 电气安全：IEC 60601-1（有源器械）
- EMC：IEC 60601-1-2
- 生物相容性：ISO 10993 系列
- 软件验证：IEC 62304
- 灭菌验证：ISO 11135/11137
- 运输/储存验证
- 有效期/货架寿命验证
- 可用性工程：IEC 62366

## Module F: 临床评价报告 (CER)

按照 MEDDEV 2.7/1 Rev.4 格式：
1. 临床评价计划 (CEP)
2. 器械描述与预期用途
3. 临床数据识别与检索策略
4. 临床数据评估（质量+适用性）
5. 临床数据分析与综合
6. 等同器械论证（如适用）
7. 收益-风险结论
8. 临床专家签字

## Module G: 上市后监督

- PMS Plan（上市后监督计划）
- PMCF Plan（上市后临床跟踪计划）
- PSUR（定期安全更新报告）——Class IIa及以上
- SSCP（安全和临床性能摘要）——Class III及植入器械

## 技术文档撰写五条黄金法则

1. **一个文件讲一件事** — 审评员不会帮你"连点成线"
2. **所有声明都必须有证据** — "安全有效"→附测试报告
3. **用表格替代文字描述** — 表格让审评员3秒找到信息
4. **第三方报告优先于内部报告** — NB审评员天然更信任外部认可实验室
5. **文件版本号+日期** — 没有版本控制的文档=无效文档，会被直接退回
