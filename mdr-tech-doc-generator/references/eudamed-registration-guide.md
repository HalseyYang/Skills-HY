# EUDAMED 注册步骤详解

> 依据：Commission Decision (EU) 2025/2371（2026-05-28 首批四模块强制）+ MDR/IVDR Article 29-31
> 状态标签：✅ 已生效（Actor / UDI / NB 证书 / MSU 四模块）｜⏳ 2026-11-28 遗留器械补录截止｜⏳ 2027-05-28 旧证书上传截止

## 一、四模块与强制时间线

| 模块 | 强制日期 | 适用范围 | 关键数据 |
|------|---------|---------|---------|
| **Actor 注册（ACT）** | ✅ 2026-05-28 | 制造商 / 欧盟授权代表（AR）/ 进口商 | 获 **SRN**——其他一切操作的前置门控 |
| **UDI / 器械注册（UDI-DI）** | 新器械 ✅ 2026-05-28；遗留器械 ⏳ 2026-11-28 | 首次投放或继续投放的 MDR/IVDR 器械 | UDI-DI + Basic UDI-DI + EMDN 代码 + 预期用途 + 分类规则 + CMR 物质声明 + 标签语言 |
| **NB 与证书（NBCF）** | 新证书 ✅ 2026-05-28 起；旧证书 ⏳ 2027-05-28 | 公告机构上传证书数据 | 最新版本证书 + 最新 NB 决定 |
| **市场监督（MSU）** | ✅ 2026-05-28 | 主管当局专用 | 制造商不直接操作，间接受影响 |

**警戒与上市后监督（VPMS）模块**：📅 未定（开发中，可能 2027）——警戒报告在模块就绪前按 MDR Article 87 时限向主管当局提交，就绪后切换 EUDAMED。

## 二、注册流程（境外制造商）

```
1. Actor 模块注册（制造商 + AR）→ 主管机构验证 → 获得 SRN
        │  ⚠️ SRN 必须在器械投放市场之前完成（前置硬条件）
        ▼
2. UDI/DEV 模块注册器械 → 分配 Basic UDI-DI → 填写 120+ 字段
        │  ⚠️ 无有效 SRN 无法进入器械注册
        ▼
3. NB 上传并链接证书 → 器械注册状态从 "Submitted" → "Registered"
        │  ⚠️ 须制造商、AR、进口商与 NB 多方协同
        ▼
4. DoC 中注明 SRN + UDI-DI + Basic UDI-DI；标签加贴 CE + UDI（人读 + 机读）
        ▼
5. 投放市场（EUDAMED 注册是合法投放的前提，分销商/医院可实时查库）
```

## 三、高频坑点（技术文档须一致）

| # | 坑点 | 后果 |
|---|------|------|
| 1 | 器械描述 / 预期用途 / 分类与技术文档、DoC 不一致 | 主管当局质疑，注册被拒 |
| 2 | Basic UDI-DI 分组不当（过度或不足分组） | 拖累追溯、技术文档、认证与注册（依 MDCG 2018-1 Rev.4：同组须共享预期用途、风险等级、设计或制造属性） |
| 3 | 遗留器械拖到 2026-11-28 截止日 | 审查时间已从数天延长至数周，逾期无法合法投放 |
| 4 | EMDN 代码选错 | 与 MDR 分类规则脱节，注册被退回 |
| 5 | 瑞士 swissdamed 与 EUDAMED 数据不互通 | 覆盖瑞士须单独注册 + 单独 CH REP，不能复用 |

## 四、技术文档须包含的 EUDAMED 数据

- UDI-DI / UDI-PI 结构、Basic UDI-DI 分组逻辑
- 制造商 SRN、AR 信息、进口商 SRN
- NB 证书编号、EUDAMED 数据库 ID
- 标签语言清单（覆盖销售的所有 EU 官方语言）

## 五、NB 产能提示

- NB 技术文档评估实际周期 13-18 个月（当前 NB 资源紧张常态）；约 40% 首次提交需补充信息（+3-6 个月）
- TÜV SÜD 丹麦 2026-06 大幅扩项（此前自 2024-04 起为丹麦唯一 MDR NB）
- 自 2027-02-25 起 NB 时限法定化（Reg (EU) 2026/977）：申请审查+签约 30 天 / QMS 审核 120 天 / 技术文档 90 天 / 发证 20 天
