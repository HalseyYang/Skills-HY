## 一、中国（CN）

### 1.1 NMPA | 《医疗器械出口销售证明管理规定》（2025年第126号）5月1日起施行 ⭐
**发布**：[国家药监局公告](https://www.gov.cn/gongbao/2026/issue_12626/202603/content_7063188.html) 2025-12-25 | **施行**：2026-05-01 | 废止2015年第18号通告

**核心变化**：

| 变化点 | 旧规（2015年第18号） | 新规（2025年第126号） |
|---|---|---|
| 证书类型 | 单一证书 | **双证书制度**：证明(I)=已注册产品；证明(II)=纯出口型（未在中国注册但具备GMP生产条件） |
| 办理时限 | 无明确规定 | **最长20个工作日**（从提交完整资料起算，补正时间不计入） |
| GMP审核 | 纯文书审查 | **可开展现场检查**（证明(II)概率更高） |
| 证书格式 | 仅中文 | **中英文双语**，与国际标准接轨 |
| 不予出具情形 | 未明确 | **严重违法失信名单**直接拒绝；虚假资料5年内不出具并移交司法 |
| 有效期 | 未明确 | 不超过注册证等证件最先到期日；第一类不超过3年 |

**企业应对**：
- 纯出口型企业：立即开展GMP合规性自查，**4月底前**完成整改
- 已注册出口企业：确认注册证有效期，优先使用线上申请系统
- 所有出口企业：建立文件化出口质量管理制度，保证产品可追溯

**编号规则**：中文 `X1药监械出X2X3号` / 英文 `No.MDX1X2X3`（X1=省份代码，X2=4位年份，X3=6位流水号）

## 二、欧盟（EU）

### 2.1 实施条例 (EU) 2026/977：NB统一程序要求 ⭐⭐（最重磅，本周全球最重要法规）
**OJ发布**：2026-05-05 | **法律依据**：MDR第36(3)条、IVDR第32(3)条（统一规范Annex VII）

**解决问题**：①NB执行尺度不一致 ②报价/时间线不透明 ③重新认证流程差异

#### 核心条款：

**第1条 — 标准化报价要求**

NB须在收到以下信息后才能出报价：制造商识别信息+SME状态、所有QMS场所、关键供应商/分包商、设备描述/预期用途/风险分类/合格评定路径、变更或重新认证范围详情。

报价**必须包含**：费用明细分解、预计时间线、附加成本估算说明。**费用增幅超原报价10%须提前告知**。30天内提供报价。

**第2条 — 合格评定最长时间线（最关键条款）**

| 评估阶段 | 最长时限 | 最大中断次数 |
|---|---|---|
| 申请审查与合同签署 | **30天** | 1次 |
| QMS审核（每个场所） | **120天** | 每场所4次 + 每增加场所+2次 |
| 技术文件/产品验证 | **90天** | 4次 |
| 重大变更评估 | NB评估30天；附加活动90天；证书补充20天 | 2次 |
| 重新认证决定 | 收到完整申请后**90天** | 4次 |
| 证书重新签发 | 最终审查后**20天** | — |

> **重要确认**：Annex IX下QMS审核与产品验证**并行运行**被明确确认为合法。

**第3条 — 时钟停止规则**
每个评估阶段有最大中断次数限制；一旦用尽，**时钟继续运行**。超过时限或用尽最大中断次数**不是拒绝签发证书的理由**（程序性问题，非实质性问题）。

**第5-6条 — 重新认证**

| 要点 | 内容 |
|---|---|
| 评估范围 | 仅关注：变更内容、PMS数据、PSUR、FSCA历史、风险更新、SOTA演变、临床/性能评价更新 |
| 不重复事项 | **不重复初始指定审核**（重大简化） |
| 证书签发 | 90天评估 + 20天签发 |
| 适用范围 | 不适用于2027-11-25前到期的证书 |

**第7条 — 结构化对话**
正式引入制造商与NB之间的结构化对话法律依据，允许提交前/后的讨论以澄清分类问题、技术文件预期和评估范围。

**实施时间线**：

| 条款 | 生效日期 | 适用范围 |
|---|---|---|
| 第1-3条（报价/时间线/中断规则） | **2027-02-25** | 2027-02-25当日或之后签署的协议 |
| 第4(1)-(3)条（监控系统） | **2027-05-25** | 2027-05-25后签署的协议 |
| 第4(4)条（年度报告） | **2028-01-01** | 所有NB |
| 重新认证条款 | **2027-11-25** | 仅适用于该日期后到期证书 |

## 附：本周补充补录

### 【补】MDCG 2021-24 rev.1 脊柱钩分类变化详注

脊柱钩（spinal hooks，用于将棒固定于脊柱的器械）此次从Class III降为Class IIb，对相关制造商的影响：

- 合格评定路径：从需要公告机构详细临床数据审核 → 可按Class IIb标准路径评估
- 认证时间线预计大幅缩短
- 需重新评估技术文件，确认符合Class IIb的Annex VIII分类规则

> ⚠️ **注意**：上述降类基于MDCG 2021-24 rev.1文件，正式实施需确认NB已开始按新分类规则评估。建议在正式认证申请前与公告机构确认。
