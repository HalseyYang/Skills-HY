# Screening And Extraction

## Inclusion Criteria

Define criteria before extracting conclusions:

- Population/domain/context
- Intervention, exposure, technology, or concept
- Outcomes or evidence types
- Publication date range
- Language
- Geography or jurisdiction
- Study/source type

## Exclusion Criteria

Common exclusions:

- Off-topic population or technology
- Non-primary source when primary evidence is required
- Superseded guidance unless historical context matters
- Abstract-only records for detailed claims
- Duplicate or derivative publication
- Low-quality commercial or promotional content

## Screening Notes

When practical, state:

- Number of sources identified.
- Number screened.
- Number included.
- Main reasons for exclusion.

Use PRISMA language for systematic-review style work, but do not claim a full systematic review unless the process actually supports it.
