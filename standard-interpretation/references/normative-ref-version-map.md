# 规范性引用文件版本映射表（V2.0）

用途：解决同一份用例中**引用标准新旧版本混用**的问题（实测：某参考版同时出现 `YY 0505` 与 `YY 9706.102-2021`），并支撑 SKILL「D 类引用标准展开」时标注【限值来源】。

## §1 医电领域常见引用标准版本映射

| 旧版（已废止/被替代） | 现行版本 | 说明 | 替换时机 |
|----------------------|----------|------|----------|
| YY 0505-2012 | **YY 9706.102-2021** | 医用电气设备 EMC 并列标准，等同 IEC 60601-1-2:2014 | 生成时一律替换为现行版 |
| GB 9706.1-2007 | **GB 9706.1-2020** | 医用电气设备通用安全要求，等同 IEC 60601-1:2005+A1 | 生成时一律替换为现行版 |
| GB/T 17626 系列（旧年号） | 当年有效版本 | EMC 基础标准簇 | 按现行有效版本取用 |
| GB 4824（旧年号） | 当年有效版本 | 工科医射频骚扰 | 按现行有效版本取用 |
| YY/T 0316-2008 | **YY/T 0316-2016** | 风险管理对医疗器械的应用 | 注明版本差异 |

> 维护规则：新增映射须同时更新本文件；**标准换版时本表必须同步**。

## §2 生成时的处理规则

1. **扫描**：生成用例时，扫描「条款要求」「前置条件」「测试步骤」「预期结果」「经验教训」五列中的引用标准号；
2. **替换**：命中 §1 左列（旧版）的，统一替换为右列现行版；
3. **告警**：脚本发现旧版引用时输出告警行；若用户明确要求沿用旧版（如旧注册单元），须在「经验教训」列注明 `【产品场景提示：沿用 <旧版标准号>，非现行版本 | 来源：用户指定 YYYY-MM-DD】`；
4. **展开标注**：D 类引用展开获得的限值，必须在「经验教训」列写 `【限值来源：<引用标准号> <条款号>】`；
5. **不确定处理**：引用标准正文无法查证时，**禁止编造限值**，改为成 1 条指向性用例 + `【需人工复核：…】`。
