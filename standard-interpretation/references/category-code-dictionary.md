# 分类代码字典（V1.0）

|----------|----------|----------|------------------|
| CM | 通用 | 跨产品通用要求、基础条款 | GB 9706.1、IEC 60601-1 |
| RF | 射频 | 射频治疗仪（Unicorn、R1 等） | YY 0789、GB 9706.203 |
| MF | 超声 | 超声/聚焦超声、HIFU | YY 0767、GB 9706.205 |
| LT | 光疗 | LED、光动力、可见光 | YY 0703、GB 9706.206 |

> **使用规则**：一条用例只能归属一个产品代码；当条款跨多类设备时，归属最贴近本批次被测产品的主类别，其余设备在「条款要求」列原样保留次属性。

## §2 测试模块代码（11 项）

| 模块代码 | 测试模块 | 覆盖要点 | 关联标准/章节（示例） |
|----------|----------|----------|----------------------|
| AP | 外观 | 整机外观、标识、外壳、铭牌、面板、配件可见性 | GB 9706.1 §7 |
| ST | 结构 | 结构强度、装配、紧固件、运动部件、机械安全 | GB 9706.1 §9、§15 |
| HW | 硬件 | 硬件电路、电源、电池、传感器、连接器、硬件功能 | GB 9706.1 §8、§13 |
| SW | 软件 | 软件功能、UI、版本、报错、容错、报警提示 | IEC 62304、YY/T 0708 |
| PF | 性能 | 输出精度、参数指标、响应时间、负载能力、稳定性 | 产品专用标准 |
| RL | 可靠性 | 寿命、耐久、长时间运行、按键/接口寿命、MTBF | GB/T 5080、IEC 60068 |
| GR | 安规-通标 | GB 9706.1 等通用安规条款：漏电流、接地、耐压、温升、防护 | GB 9706.1 §8、§11、§13 |
| PR | 安规-专标 | 产品专用安规条款（射频/激光/超声等专用安全标准） | YY 0789、GB 9706.203、GB 7247.1 |
| FT | 功能 | 功能流程、模式、报警提示、联锁、互锁、暂停/终止 | 产品专用标准功能章节 |
| ESD | EMC（静电） | 静电放电抗扰度（接触放电 + 空气放电） | GB/T 17626.2、YY 0505、IEC 60601-1-2 |
| EMC | EMC | EMC 其他项目：辐射骚扰、射频抗扰度、浪涌、脉冲群、工频磁场、传导骚扰、谐波闪烁 | GB/T 17626 系列、YY 0505、IEC 60601-1-2 |

> **关键说明**：
> 1. **ESD 单列**——静电放电在医美设备（特别是带电治疗头、皮肤接触面）注册送检中高频出现、易出问题，独立为一类便于快速筛选风险用例。
> 2. **GR vs PR 区分**——GR 是 GB 9706.1 通用条款（对所有有源医疗器械适用），PR 是各产品专用安标条款（如 YY 0789 射频专用）。两者都是安规，但不能混用。
> 3. **FT vs SW 区分**——FT 关注设备层面的功能行为（人机交互、报警、联锁）；SW 关注软件内部逻辑（算法、容错、版本）。同一报警功能在 FT 中验证"是否报警"，在 SW 中验证"软件能否正确触发"。

## §3 用例编号规则

格式：`<产品代码>-<测试模块代码>-<5 位流水号>`

- 示例：`CM-GR-00001`（通用-安规通标-00001）
- 示例：`RF-FT-00003`（射频-功能-00003）
- 示例：`LS-PR-00012`（激光-安规专标-00012）

**流水号策略**（默认二选一，使用前必须明确告知用户）：

1. **全文件连续**（默认）：从 00001 起，跨模块连续递增，文件内唯一；
2. **按测试模块分桶**：每个测试模块独立从 00001 起，便于按模块筛选。

## §4 字典引用方式

- Excel 文件的「测试项目分类」列通过数据校验下拉引用「字典」sheet，字典 sheet A/B 两列：`<产品代码>-<测试模块代码>`、`<产品代码>-<测试模块代码> <测试模块名称>`；
- 字典 sheet **D/E 两列**为「验证方式标签」区（见 §5），由 `scripts/init_workbook.py` 自动写入；
- 字典新增项必须同步更新本文件与 SKILL.md。

## §5 验证方式标签字典（V2.0 新增，6 项）

用途：承载每条用例的**证据类型**。因 12 列表头冻结，标签**不新增列**，而是写入「关键词」列首位（见 `column-definition.md` §2.4）。

| 标签 | 含义 | 默认归属模块建议 | 典型条款 |
|------|------|------------------|----------|
| `实测` | 仪器测量 / 环境试验 / 通电操作 | PF / PR / ST / EMC / ESD | 201.10.102、202.6.2.3 |
| `目击检查` | 外观、标识、显示可读性现场目测 | AP | 201.7.4.101 |
| `文档审查` | 核对使用说明书 / 技术说明书条目完备性 | AP | 201.7.9.2.1、201.12.1.103 |
| `风险文档审查` | 核对风险管理文档条目完备性 | SW / PR | 201.10.103、201.13 |
| `软件资料审查` | 核对软件生存周期 / PEMS 文档 | SW | 201.14 |
| `引用` | 指向引用标准章节（A 类章级兜底） | 按该章主旨归模块 | 201.4、201.5、201.8 |

使用规则：

1. 每条用例**有且仅有一个**标签，置于「关键词」列首位；
2. 禁止自造标签；
3. A 类章级兜底条固定用 `引用`；
4. 标签与模块代码可自由组合（如 `MF-AP 外观` + `文档审查`）。
