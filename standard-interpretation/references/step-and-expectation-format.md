# 测试步骤与预期结果格式范式（V3.0 新增）

本文件响应 V3.0 针对性优化需求：
1. **预期结果**：根据标准内容总结，**分条呈现**，语言简洁，内容清晰；
2. **测试步骤**：条款中出现"按其他标准执行（如 IEC/TS 62556 方法）"时，**展开该方法**，而不是把标准条款当步骤；
3. **条款分解为步骤**：**全面细致**，**参数清晰**。

---

## §1 测试步骤六要素（S1-S6）

一条用例的「测试步骤」由下列要素构成；**条款原文写到的要素必须出现，未写的不补造**。

| 编号 | 要素 | 必备性 | 写法要求 | 示例 |
|------|------|--------|----------|------|
| S1 | 试验配置与连接 | 条款规定了布置时必备 | 写明受试部件、夹具、探头/传感器位置、连接关系、模拟负载 | `将水听器固定于声束轴线距换能器表面 5 mm 处` |
| S2 | 设备/仪器设置 | 条款给了量值时必备 | 量值 + 单位 + 允差；仪器量程/精度要求 | `设置输出功率为标称值 Po（允差 ±5%）` |
| S3 | 施加/操作动作 | 必备 | 动作动词 + 对象 + 参数（时长/电平/频率） | `连续施加输出 60 s` |
| S4 | 工况切换/循环 | 条款要求多工况时必备 | 明确列出各工况/档位/模式，注明重复次数 | `分别在连续与脉冲模式各测 3 次` |
| S5 | 观察与记录 | 必备 | 写明观察对象、记录字段、数据点位置与数量、数据处理方式 | `记录每次声功率值，计算算术平均值` |
| S6 | 异常与安全处置 | 条款含中止/保护要求时必备 | 写明触发条件与处置动作 | `出现超温报警立即中止并记录` |

**步骤闭环要求**：一条用例的步骤合起来必须能"独立执行一次并得出一个合格结论"。

## §2 参数书写规范

| 参数类型 | 写法 | 反例 |
|----------|------|------|
| 数值 + 单位 | `43 ℃`、`100 mW/cm²`、`60 s`、`5 mm` | `温度上限`、`较短时间` |
| 允差 | `±10%`、`±1 ℃`、`≥10 Hz` | `约`、`左右` |
| 区间 | `5~35 ℃`（须有出处，否则不得写） | 凭惯例补写区间 |
| 工况 | `连续模式 / 脉冲模式`、`低/中/高功率档` | `各模式` |
| 次数 | `重复 3 次取平均` | `多次测量` |
| 数据点 | `声束轴线上间隔 5 mm 的 7 个点` | `若干点` |

**红线**：参数的取值必须出自条款原文或已被展开的引用标准；**禁止用实验室惯例补造**，只能进「经验教训」列作【产品场景提示】。

## §3 预期结果分条范式

### §3.1 分条规则

- 多判据 → `1) …；2) …；3) …`，Excel 单元格内换行分条；
- 一条一判据，2-5 条为宜；
- 单条 ≤60 字；
- 句式 = **主语 + 量化判据**；
- 判据后**不加收尾语**（写"符合要求即通过"即违规）。

### §3.2 场景化模板

| 用例类型 | 预期结果模板 |
|----------|--------------|
| 物理量限值（B 类） | `1) <对象> ≤/≥ <数值><单位>（<状态>）；2) <对象> 在 <条件> 下 ≤/≥ <数值><单位>` |
| 响应时间/告警（B 类） | `1) <事件> 发生后 <时间> 内 <动作/状态变化>；2) 同时发出 <声/光> 报警` |
| 文档审查（C 类） | `文档应包含下列条目且内容完整：1) <条目1>；2) <条目2>；3) <条目3>。缺任一项即判不符合` |
| 风险文档审查（C 类） | `风险管理文档应包括：1) <条目1>；2) <条目2>；且与 <对应安全要求> 一一对应。缺项即判不符合` |
| 引用展开（D 类） | 按展开后的各判据分条；「经验教训」列须有【限值来源】 |
| A 类章级兜底 | 单条：`通用标准第 <X> 章全部适用条款均满足要求` |

### §3.3 正反例对照

| 场景 | ❌ 错误 | ✅ 正确 |
|------|---------|---------|
| 温度+超温停机 | `温度符合要求，超温时能停止，无异常，符合要求即通过` | `1) 治疗头表面温度 ≤43 ℃；2) 超限后 2 s 内输出降至 0 W；3) 同时发出声光报警` |
| 说明书条目 | `说明书齐全，满足标准要求` | `说明书应包含下列条目且内容完整：1) 禁忌症清单；2) 电气安装建议；3) B 型应用部分危害提醒。缺任一项即判不符合` |
| 输出功率误差 | `输出功率误差在标准允许范围内` | `各设定档位下输出功率实测值与标称值偏差 ≤±10%` |
| 多工况 | `各模式下均正常` | `1) 连续模式输出稳定，波动 ≤±5%；2) 脉冲模式峰值功率偏差 ≤±10%；3) 两模式切换无中断` |

## §4 引用方法展开速查（配合 `test-method-toolkit.md`）

| 条款写法 | 处理路径 | 步骤产出 |
|----------|----------|----------|
| `按 IEC/TS 62556 规定的方法测量声功率` | A（库内） | 水听器布置 → 设定输出 → 采样 → 计算平均（4-5 步） |
| `按 GB 9706.1 第 8 章测量漏电流` | A（库内） | 接测量网络 → 施加电压 → 分状态测量 → 记录 |
| `按 GB/T 17626.2 进行静电放电试验` | A（库内） | 布置 EUT → 设定电平/极性 → 逐点放电 → 观察记录 |
| `按 YY 9706.102 进行辐射抗扰度试验` | A（库内） | 布置 → 扫频 → 施加场强 → 监测试验状态 |
| `按 ISO 10993-X 进行生物相容性试验` | B（库外） | 保留简写式 + 【需人工复核】（方法由第三方实验室执行） |

> 路径 A：不得出现标准号；路径 B：允许保留标准号，**必须在「经验教训」列标注【需人工复核】**。
