# 公众号搜索与正文采集

给 DeepSeek Harness 一个关键词，搜索相关文章，再挑选公开文字文章保存到本地。不限于 AI 主题，但结果受搜索索引、时间范围和站点访问情况影响。

## 开始使用

1. 准备能正常聊天的 DeepSeek Harness 和 Node.js 22+。
2. 解压压缩包，添加工作区，选中直接包含 SKILL.md 的 wechat-topic-research 文件夹。
3. 新建会话，发送：

> 读取当前目录的 SKILL.md，检查 Node.js 版本，在本目录运行 npm ci --ignore-scripts --no-audit --no-fund，再运行 npm test。先不搜索，不安装到全局目录。

首次准备依赖需要联网。不要只复制 SKILL.md，也不要全局安装依赖。此包不包含模型服务，Harness 的模型仍需自己配置。

## 只找参考

> 使用当前工作区的公众号搜索 Skill，找近30天“DeepSeek Harness 插件”的相关文章，保留5篇，列出标题、公众号、日期、摘要和原文入口。先不下载正文。

## 搜索并保存正文

> 使用当前工作区的公众号搜索 Skill，搜索近30天“家庭收纳”的相关文章，挑1篇公开文字文章保存正文。请实际执行，成功后给我 Markdown 文件路径、标题、公众号和主要内容。失败就说明原因，不能拿摘要代替正文。遇到验证立即停止。

关键词可替换。默认一次搜索最多10条，挑最多3篇逐篇采集。也可以直接给一条公开微信文章链接，让它保存该篇正文。

成功时会生成 article.md（文字）、article.json（元数据）、source.html（页面存档）和 result.json（运行状态）。只有 body_saved 才表示正文保存通过检查；仍应核对标题、账号、日期和内容是否匹配。

## 限制

- 不下载图片、视频、评论，不抓整号历史，不获取阅读量。
- 日期来自搜索索引；正文日期无法识别时会标记，不能自行补写。
- 验证、403、429立即停止，不循环重搜。可在自己的浏览器正常处理后提供公开原文链接。
- 搜索无结果不代表该主题没有文章；中转无法解析不代表正文不存在。
- 部分付费页、删文、纯图片或动态页面无法采集。
- 仅用于少量公开资料研究，遵守站点规则及原作者版权，不批量转载全文。

## 文件组成

```yaml
wechat-topic-research:
  SKILL.md: Harness 使用规则
  使用说明.md: 安装与提问示例
  scripts: 搜索、正文采集和保存
  tests: 自动化测试
  package.json: Node 依赖
  package-lock.json: 依赖版本
  LICENSE.upstream: 搜索选择器参考项目的许可
```

需要长期在其他工作区调用时，可以再让 Harness 确认当前 DSH_HOME，把此完整文件夹安装到它的 skills 下。安装会涉及当前工作区外的写入，先核对操作再批准；不要覆盖不同的已有文件。完成后新建会话实际搜索验证。
