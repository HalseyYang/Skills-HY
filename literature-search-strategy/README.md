# 文献检索词与检索式生成 skill

> 医疗器械 CER 同品种临床评价——从「产品说明书」到「七个数据库可直接粘贴的检索式」的按轮次工作流。

---

## 一、这套东西解决什么问题

做同品种临床评价时，检索策略最容易出现两类问题：

1. **漏检** —— 厂家并购改名、品牌英文商标与拼音无关、中文产品命名不统一，都会让一批文献整体消失；
2. **无法解释** —— 加严时换了词、切了字段、用了 NOT，审评问"为什么当时这么搜"答不上来。

本 skill 用**三轮递进 + 三条铁律**把这两类问题压住：

```
一轮 = 单元1（产品/技术名） AND 单元2（厂家名）         ← 摸底，绝不加严
二轮 = 一轮 AND 单元3（使用部位 / 适应证）              ← 仍用全文，靠加词收敛
三轮 = 二轮 AND 单元4（精确产品名）                     ← 排除同集团其他产品
```

**三条铁律**（破了整套方法就失效）：

| # | 铁律 | 为什么 |
|---|---|---|
| 1 | 只在末尾 `AND` 叠加新单元，**绝不删改已有单元** | 命中集单调收窄，`三轮 ⊆ 二轮 ⊆ 一轮` 才可逐级对拍 |
| 2 | **字段始终用全文**，不切题摘降噪 | 一切字段，正文提及但题摘未提的文献整批丢失 |
| 3 | **禁用 NOT** 排除词 | 易误杀；一律靠加限定词收敛 |

## 三、怎么安装

**WorkBuddy 用户**：把整个文件夹复制到

- 个人级（所有项目可用）：`C:\Users\<用户名>\.workbuddy\skills\`
- 项目级（团队共享）：`<项目目录>\.workbuddy\skills\`

复制后重启会话即可被自动识别。**不用**改文件名，目录名须与 `SKILL.md` frontmatter 里的 `name` 一致。

**非 WorkBuddy 用户**：`SKILL.md` 本身是一份完整的方法论手册，可直接阅读；
`scripts/` 里的三个脚本是独立 Python 脚本，不依赖 WorkBuddy，按第五节直接跑即可。

## 五、怎么用

### 5.1 三个脚本的用法

每个脚本**只需改顶部的 CONFIG 区**，其余全部自动生成：

| 字段 | 填什么 |
|---|---|
| `OUT` | 输出路径。脚本自带防覆盖：同名文件自动加 `_1` / `_2` 序号 |
| `PRODUCT_CN` / `SUBTITLE` / `SCOPE_NOTE` | 封面文字 |
| `CN_TERM` / `CN_TERMS` | 单元 1 中文词（命名不统一时用 `CN_TERMS` 产品名族 OR 枚举） |
| `KEEP_ALWAYS` | ★ 白名单：有注册出处的官方名强制保留，不被自动去重删掉 |
| `BRAND_TERMS` / `PREFIX_TERMS` | 单元 1 英文品牌变体与技术词 |
| `MANUFACTURERS` | 单元 2 厂家名称，按并购时序分时期，`en` 进英文库、`cn` 进中文三库 |
| `SITE_CN` / `SITE_EN` | 单元 3（仅二轮起） |
| `SPEC_TERMS` | 单元 4 精确产品名（仅三轮） |

```bash
python gen_round1_doc.py     # 生成《…一轮检索词与检索式.docx》
python gen_round2_doc.py     # 生成《…二轮检索词与检索式.docx》
python gen_round3_doc.py     # 生成《…三轮检索词与检索式.docx》
```

**下一轮怎么接**：把这一轮的 CONFIG 复制到下一个脚本，**单元 1/2（/3）一字不改**，
只追加新单元字段。脚本共用同一套 CONFIG 约定与排版样式。

### 5.2 轮次推进纪律（重要）

**不要一次把三轮全生成。** 每轮的判定必须建立在前一轮的**真实命中数**上：

| 单库命中数 | 判读 | 动作 |
|---|---|---|
| 0 条 | 过严，或该库不收录 | 拆开单跑；厂家 AND 过严则厂家词退到 OR 层 |
| 1–20 条 | 偏少 | 放宽：删 AND 段；补品牌拼写变体、补子品牌名 |
| 20–300 条 | ★ 召回健康 | **定稿**，进入查全验证 |
| > 300 条 | 过宽 | 进下一轮，加限定词 |

**★ 无明确使用部位的产品**（如冲洗器、敷料、冲洗液、耦合剂等，适用范围不指向解剖部位）：
不要硬凑"部位"方向的场景词，改走 SKILL.md 里的 **路径 C / D**——
先收敛到**注册证三件套**（注册证名称 + 商品名 + 厂家简称，停止推测"还可能叫什么"），
再考虑**限定发表年份**（上市时间起点 → 近 10 年 → 近 5 年）。

### 5.3 定稿前必做：查全验证

取已知的金标准文献（说明书参考文献 / 已知同品种文献），在终版检索式中逐条回检。
任一条未被召回 → 记录它用的产品名 / 厂家写法 → 以 OR 补入词表 → **全库重跑** →
在筛选报告中写明补词依据与来源。

## 六、七个数据库的语法速查

| 数据库 | 入口 | 字段 | 引号 | 逻辑词 |
|---|---|---|---|---|
| 中国知网 | 高级检索 → 专业检索 | `FT='词'` | `'词'` | `AND` / `OR` |
| 万方 | 高级检索 → 专业检索 | `全部:(词)` | 含非字母数字才加 `" "` | 小写 `and` / `or` |
| 维普 | 高级检索 → 专业检索 | `U=词` | `""` | **`AND` / `OR`**（不用 `*`/`+`） |
| PubMed | 检索框 | 不加字段 | `"词"` | `AND` / `OR` |
| Embase | 检索框 | 不加字段 | `'词'`，截词 `*` | `AND` / `OR` |
| Cochrane | Search Manager | `:ti,ab,kw` | `"词"` | 行号式 `#1 AND #2` |
| ClinicalTrials.gov | Other terms 框 | 无 | `"词"` | `AND` / `OR` |

**★ 检索式一律单行**——复制粘贴时换行会被多数数据库当成语句结束，导致静默零命中。
唯一例外是 Cochrane 的行号式（必须逐行输入）。

## 七、分享版的脱敏说明

本版相对内部工作版做了如下处理，供接收方知悉：

| 类别 | 处理 |
|---|---|
| 本单位名称 | 已去除，改为中性表述 |
| 内部协作链接（课件 / 会议录像） | 链接已删除，仅保留来源性质说明 |
| 具体注册证号 | 泛化为「注册证 A / B」「某进口注册证（旧版）」等，保留教学逻辑 |
| 具体项目语境（指向特定委托关系的表述、具体申报产品品类、国产客户名） | 已泛化 |
| `gen_device_verify.py` | 整体移除（正文为客户项目实例数据） |
| 备份目录、Python 缓存 | 已清理 |

**保留**的是公开上市器械的产品名与公开注册口径（如进口射频消融系统、预充式导管冲洗器等）——
这些信息来源于 NMPA / FDA 公开数据库与公开文献，是方法论教学案例的主体，去掉会导致文档无法阅读。
